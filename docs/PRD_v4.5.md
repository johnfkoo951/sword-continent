## 1. 프로젝트 개요 (Executive Summary)

### 1.1 게임 컨셉
**소드 콘티넌트(The Sword Continent)**는 거대한 대검 형태의 판타지 대륙을 무대로, 플레이어가 5대 왕국을 가로지르며 **26개 스테이지**를 정복하고 사탕을 파밍하여 11대 신급 스킨, 전설의 무기, 그리고 좀비슈터 레거시 스킬을 해금하는 **3D 협동 보스 레이드 액션 RPG**이다.

### 1.2 핵심 개발 철학
1. **플레이어 주도적 피드백 루프**: 태용 디렉터의 직관적인 게임 기획(26스테이지, 왕국 성채, 스파이 은신, 전설 스킬, 도우미 시스템, 왕 격파 엔딩)을 실시간 반영.
2. **광활한 오픈 필드와 직접 들어가는 대성채**: 시야를 가리는 어두운 돔을 완전히 삭제하고, 성문이 뻥 뚫려 있어 직접 걸어 들어갈 수 있는 3D 대성채(내부 대리석 알현실 광장, 붉은 주단 카펫, 8대 타오르는 횃불 기둥, 황금 옥좌 단상)를 구축하여 성 안팎을 넘나드는 역대급 현장감 제공.
3. **자립적 파밍과 다채로운 성장**: 사탕 30개당 1레벨 업, 사탕 섭취 시 +12 HP 회복, 200사탕 정가 스킨 해금, 그리고 80~150사탕 레거시 스킬 상점을 통해 정통 게이머의 깊은 성취감 부여.
4. **가족 협동 멀티플레이**: 산이 형과 폰 2개로 방 코드(`7794`)를 통해 언제 어디서든 함께 뛰는 실시간 협동 보스 레이드 지원.
5. **명확한 최종 목표**: 26스테이지 최종 대성채의 폭군 대검왕, 그리고 50마리 처치 후 황금 피리로 직접 소환하는 **거대 왕드래곤 대군주**를 무찌르면 게임 클리어 엔딩 연출 발동.

## 3.5 🐉 v4.5 왕드래곤 3D 리모델링 (King Dragon Remodel) — 핵심 업데이트

### 3.5.1 개요
태용 디렉터가 v4.4의 왕드래곤을 보고 **"이거 드래곤 멋지게"**라고 피드백했다. v4.4의 드래곤은 둥근 구체 두개골·동그란 눈·직선 삼각형 날개라 "동글동글하고 귀여운" 인상이었다. v4.5는 **날카롭고 웅장하며 포스 넘치는 판타지 제왕 드래곤**으로 3D 외형을 전면 재설계했다(Three.js r128 프리미티브 + 커스텀 BufferGeometry 약 289파트 / 6,200 트라이앵글, 전부 `flatShading` 각진 면).

### 3.5.2 새 3D 모델 명세 (둥근 공 탈피)
- **두개골(가장 중요)**: 구체 대신 8각 코너로 직접 찍은 **각진 프리즘 두개골**(뒤가 넓고 앞으로 좁아짐) + **길게 뻗은 상악 주둥이**(정면 폭 1.4 → 끝 0.4로 테이퍼, 아래로 기울어짐) + **콧등 능선** + **각진 아래턱**(브레스 시 0.75rad까지 벌어짐).
- **눈**: 정면 동그란 눈을 없애고, **불쑥 튀어나온 각진 눈두덩 선반(brow ridge) 그늘 아래**에 가로로 째진 황금 눈(가로 0.5 : 세로 0.22 알몬드형) + 세로 동공 + 글로우 스프라이트. 정면에서 미간이 찌푸려진 사나운 인상.
- **뿔**: 뒤로 크게 휘어 오르는 **주 뿔 2쌍**(각 4~2마디, 검붉은 뿔질 → 끝은 황금) + 이마 뿔 + 콧등 가시 + 턱수염 가시 + 볼·광대 가시.
- **왕관**: 이마 위에 얹힌 **8각 뾰족 황금관**(판 8장 + 가시 8개, 앞뒤 1.9m 장창형 + 붉은 보석과 발광).
- **목**: **전역 좌표 기준 방향으로 계산한 8마디 S자 목**(어깨에서 앞으로 솟구쳤다 꺾여 머리를 내밈). 마디마다 기본 굽힘 quaternion을 저장하고 그 위에 미세 물결을 얹어 이음새가 드러나지 않는다. 목덜미 가시 8쌍 + 황금 목걸이 마디 + 목 아래 판금 고리(8장).
- **몸통**: 가슴이 넓고 허리가 잘록한 **각진 비늘 몸통**(10각 튜브, 7단 반경 변화) + **등 척추 가시 10쌍**(어깨에서 가장 높고 금빛 끝) + **겹쳐 포개진 가슴 판금 5장**(강철 + 금테) + 가슴 중앙 황금 문장(옥타헤드론 + 토러스) + 배 비늘판 6장 + 옆구리 비늘판 12장 + **어깨 갑옷 3장+금 가시**(날개 뿌리).
- **날개**: 직선 삼각형을 버리고 **다관절 박쥐/용 날개**. 어깨 → 팔꿈치 → 손목 관절(금빛 옥타헤드론) + **날개 손가락 뼈 4개**가 부챗살로 뻗고, 그 사이 5개 막 패널이 **오목한 톱니(찢긴 날개) 실루엣**을 만든다(진홍/흑 2색 교차 + 손끝 발톱 + 손목 발톱). 한쪽 스팬 약 21m.
- **꼬리**: **S자로 길게 가늘어지는 9마디 꼬리**(반경 1.4 → 0.13) + 등지느러미 가시 8개 + 끝에 **황금 창날 촉(3.4m)과 양쪽 갈고리**.
- **네 발**: 각진 허벅지·정강이 + 무릎 판금 + 황금 발톱 3개씩, 호버링하며 움켜쥔 자세.
- **가시성(어두운 성채 대응)**: 구형 오라(모델을 가리던 붉은 반투명 돔)를 **제거**하고, 대신 ①얼굴 전용 포인트광 ②뒤쪽 림라이트 2기 + 옆구리 앰버광 2기 ③비늘 emissive 0.5~1.0 ④금속 부품 metalness 0.85~1.0 로 실루엣과 비늘·뿔·날개 윤곽이 성채 조명에서도 선명하다. 바닥엔 황금 회전 링 + 궤도 불티 16개만 남겼다.

### 3.5.4 스테이지 진행 규칙 (v4.5 변경)
- **피리 왕드래곤은 1~25스테이지 어디서든 소환 가능**. 격파하면 `GAME CLEAR`가 아니라 **사탕 대폭발 + "🐉 격파!! STAGE n+1로 진격!!" 연출 후 `advanceStage()`** 로 다음 스테이지에 정상 진입한다(v4.4에서는 1스테이지에서 잡으면 곧바로 엔딩이 떠서 용이 1스테이지에만 있는 것처럼 보였다).
- **GAME CLEAR는 26스테이지(최종)에서만** — 최종 왕드래곤/보스 격파 시 `triggerKingEnding()`.
- 스테이지 보스(15·20·26)도 같은 드래곤 전투 AI를 쓴다(화염 브레스·꼬리 강타·화염 파동 + 목·날개·꼬리 애니메이션).
- 드래곤 위치 제한을 성채 고정값(z −88~−20)에서 **플레이어 기준 ±75m**로 바꿔 평원·성채 어디서든 플레이어를 따라온다.
- 스테이지 보스가 살아 있는 동안에는 피리 소환을 막는다(보스 HP 바 꼬임 방지).
- `advanceStage()`의 옛 문구 "18스테이지 완전 정복" → **"26스테이지 완전 정복"**으로 수정.

### 3.5.5 등장 연출 (피리 선율 후 1.2초)
1. 황금 피리 5음계 선율 + 황금 음파 링 3개 확산.
2. `playDragonRoar()` 저음 3중 포효 + 화면 골드 플래시 + 카메라 셰이크 1.1.
3. 화염 기둥(높이 46m) + 충격 링 4개 + 불티 파편 70개.
4. 드래곤이 하늘(y=32)에서 급강하 → 호버(y≈4.0, ±0.55m 부유) 후 전용 HP 바 등장.
5. 스테이지 보스 드래곤은 필드 상공 y=30에서 같은 연출로 강림한다.

### 3.5.6 전용 HP 바·공격 패턴
- 보스명 `🐉 [왕드래곤] 붉은비늘 대군주`, HP `7,000 + 스테이지 인덱스 × 600`.
- HP 바 그라디언트 `#ff2d00 → #ffb703 → #ffe066` + 경고줄 `🐉 화염 브레스 · 화염 파동 · 꼬리 강타 주의!!`.
- 공격 3종(쿨 3.2~5.0초): 🔥 화염 브레스 42%(3연발 부채꼴 5발, 피해 14) / 💥 꼬리 대지 강타 30%(지진파, 점프 회피, 20) / 🌪️ 날개 강풍·화염 파동 28%(폭 30m 파동벽, 17m/s, 22).
- 격파 보상: 사탕 90+160개, 왕관 파편 90개, 카메라 셰이크 1.3, 용의 비명 → 승리 팡파르.
