## 1. 프로젝트 개요 (Executive Summary)

### 1.1 게임 컨셉
**소드 콘티넌트(The Sword Continent)**는 거대한 대검 형태의 판타지 대륙을 무대로, 플레이어가 5대 왕국을 가로지르며 **26개 스테이지**를 정복하고 사탕을 파밍하여 11대 신급 스킨, 전설의 무기, 그리고 좀비슈터 레거시 스킬을 해금하는 **3D 협동 보스 레이드 액션 RPG**이다.

### 1.2 핵심 개발 철학
1. **플레이어 주도적 피드백 루프**: 태용 디렉터의 직관적인 게임 기획(26스테이지, 왕국 성채, 스파이 은신, 전설 스킬, 도우미 시스템, 왕 격파 엔딩)을 실시간 반영.
2. **광활한 오픈 필드와 직접 들어가는 대성채**: 시야를 가리는 어두운 돔을 완전히 삭제하고, 성문이 뻥 뚫려 있어 직접 걸어 들어갈 수 있는 3D 대성채(내부 대리석 알현실 광장, 붉은 주단 카펫, 8대 타오르는 횃불 기둥, 황금 옥좌 단상)를 구축하여 성 안팎을 넘나드는 역대급 현장감 제공.
3. **자립적 파밍과 다채로운 성장**: 사탕 30개당 1레벨 업, 사탕 섭취 시 +12 HP 회복, 200사탕 정가 스킨 해금, 그리고 80~150사탕 레거시 스킬 상점을 통해 정통 게이머의 깊은 성취감 부여.
4. **가족 협동 멀티플레이**: 산이 형과 폰 2개로 방 코드(`7794`)를 통해 언제 어디서든 함께 뛰는 실시간 협동 보스 레이드 지원.
5. **명확한 최종 목표**: 26스테이지 최종 대성채의 폭군 대검왕, 그리고 50마리 처치 후 황금 피리로 직접 소환하는 **거대 왕드래곤 대군주**를 무찌르면 게임 클리어 엔딩 연출 발동.

## 2. 26스테이지 대원정 및 5대 판타지 왕국 체계

### 2.1 5대 왕국 및 26스테이지 로드맵
- **🌿 풀 왕국 (Green Realm / Stages 1~5)**: 그린하트 대평원, 엘름우드 에메랄드 숲, 리버데일 고대 성벽 유적, 스톤브릿지 협곡
  - **Stage 5 보스**: 👑 고대 성채 수호 골렘 (HP 1,500)
  - **왕국 성채**: 담쟁이덩굴과 이끼로 뒤덮인 고대 에메랄드 석조 성채
- **🐱 캣 왕국 (Cat Realm / Stages 6~10)**: 포퍼 항구 황금 백사장, 위스커윈드 왕실 야자수 회랑, 폴리 해안 크리스탈 동굴, 황금 스핑크스 사원
  - **Stage 10 보스**: 👑 황금 메카 타이탄 냥이 (HP 3,200)
  - **왕국 성채**: 거대 고양이 귀 지붕과 황금 발바닥 문장을 새긴 캣 스핑크스 궁전 성채
- **❄️ 얼음 왕국 (Ice Realm / Stages 11~15)**: 글레이셔 피크 다이아 설원, 프로스트할렘 빙하 협곡, 절대영도 블루 크리스탈 동굴, 눈보라 평원
  - **Stage 15 보스**: 👑 절대영도 프로스트 드래곤 (HP 5,500)
  - **왕국 성채**: 빛나는 푸른 서리 수정과 첨탑을 가진 다이아몬드 글레이셔 성채
- **🔥 불 왕국 (Fire Realm / Stages 16~20)**: 애쉬폴 마그마 화산 평원, 몰튼홀드 흑요석 성채 외곽, 인페르노 분화구 성문, 헬파이어 회랑
  - **Stage 20 보스**: 👑 인페르노 볼케이노 타이탄 (HP 8,000)
  - **왕국 성채**: 붉은 용암 줄기와 불타는 화로가 타오르는 흑요석 인페르노 요새
- **⚡ 천공 뇌신 왕국 (Sky Realm / Stages 21~25)**: 천공 썬더클라우드 번개 제단, 부유섬 전광석화 회랑, 뇌신 대성전 계단, 폭풍우 성채 정문
  - **Stage 25 보스**: 👑 천공의 번개 대군주 (HP 11,000)
  - **왕국 성채**: 구름 위에 떠 있는 순백의 대리석 기둥과 피뢰침 첨탑을 갖춘 천공의 번개 성채
- **👑 FINAL RAID (Stage 26)**: 소드 대륙 최종 왕좌 성채
  - **Stage 26 최종 보스**: 👑 **소드 대륙의 폭군 대검왕 (The Tyrant Sword King)** (HP 16,000)
  - **클리어 조건**: 왕을 죽이면 끝!! 대검왕 격파 시 왕관 파편 비산과 함께 게임 클리어 엔딩 모달 발동!

## 3. 신규 시스템 명세 (v4.0 Updates)

### 3.1 🤝 도우미 냥냥이 컴패니언 (Helper Companion)
- **개요**: 플레이어의 우측 옆에서 상시 비행 동행하는 3D 냥냥이 서포터.
- **주요 기능**:
  1. **자동 사탕 자석 파밍**: 반경 14m 이내의 사탕을 자석처럼 플레이어에게 흡수 전달.
  2. **엄호 버블 사격**: 1.3초마다 반경 28m 내 가장 가까운 적을 탐색해 240 대미지 유도 버블탄 자동 연사.
  3. **긴급 힐링 팩 투척**: 플레이어 체력이 35% 이하로 떨어지면 15초 쿨타임으로 `💚 긴급 회복 팩 (+35 HP)` 투척.
  4. **ON/OFF 토글**: 우측 하단 `[🤝 도우미]` 버튼으로 언제든 자유롭게 소환/휴식 전환 가능.

### 3.2 🕵️‍♂️ 신규 스킨: 그림자 시크릿 스파이 요원
- **디자인**: 시크한 블랙 트렌치코트, 페도라 중절모, 선글라스를 착용한 첩보 요원.
- **스탯**: 공격력 x2.0, 이동속도 x1.4.
- **고유 궁극기**: `🕶️ 그림자 은신 백스탭`
  - 4초간 완전 반투명 은신(투명도 25%) 상태로 돌입.
  - 은신 중 적 어그로 해제 및 고속 기동.
  - 다음 공격 시 적 등 뒤로 순간 침투하여 **500% (5배) 백스탭 크리티컬 대미지** 폭발 (`💥 CRIT! -1800 (BACKSTAB)` 팝업).

### 3.3 🔮 좀비슈터 전설 스킬 상점 (Legacy Skills Shop)
1. ☄️ **메테오 슈퍼 낙하** (100 사탕 / 쿨 7.0초): 하늘에서 3개의 거대 운석 소환 폭격 (반경 20m, 1,200 광역 대미지).
2. ⚡ **플라즈마 관통 레이저** (80 사탕 / 쿨 5.5초): 전방 50m 일직선 관통 파괴 광선 (850 관통 대미지).
3. ❄️ **블리자드 절대영도 동결** (120 사탕 / 쿨 8.0초): 반경 25m 적 전원 8초간 얼음 큐브 동결 + 500 대미지.
4. 🐱 **냥냥이 어깨 탑승 포격** (150 사탕 / 쿨 12.0초): 냥냥이가 어깨에 올라타 20초간 유도 버블탄 자동 연사 (350 대미지).

- **장착 UI**: 상점에서 장착 시 화면 우측 하단 스킬 버튼 슬롯에 연동되어 실시간 발동.

## 3.5 🐉 v4.4 왕드래곤 대군주 강림 (King Dragon) — 핵심 업데이트

### 3.5.1 개요
v4.3의 "50마리 처치 → 전설의 황금 피리 🪈 → 국왕 소환" 흐름은 그대로 두고, **소환되는 보스를 평범한 국왕 모델에서 성채 옥좌 위에 강림하는 거대 3D 왕드래곤으로 완전 교체**했다. 기존 26스테이지·5대 왕국 성채·`🔮 스킬 쓰는 곳` 패널·11대 스킨·도우미 냥냥이·2인 멀티(방 7794)는 전부 유지.

### 3.5.2 3D 왕드래곤 모델 (Three.js 프리미티브 약 45개 파트)
- **몸통**: 붉은 비늘 몸통(가슴·배·골반 3단) + 황금 배 판금 7장 + 등 황금 가시 12개 + 옆구리 금빛 비늘판 12개. 가슴 중앙에 황금 문장(옥타헤드론 + 토러스 링).
- **목**: 5마디 중첩 그룹(앞으로 0.45rad 숙임)이 매 프레임 사인파로 꿈틀거림.
- **머리**: 두개골 + 주둥이 + 코뿔 + 위/아래 이빨 5+5 + 벌어지는 아래턱(브레스 시 0.75rad까지 개방) + **빛나는 눈**(붉은 안광 링 + 황금 눈동자 + 세로 동공 + 발광 글로우) + 눈썹 뿔. 두개골 반경 2.05m로 몸통 대비 과장.
- **황금 왕관**: 반지름 1.3m 오픈 실린더 밴드 + 왕관 뾰족이 8개 + 붉은 보석, 천천히 회전.
- **날개**: 한쪽 스팬 21m(양 날개 42m급). 뼈대 5개 + BufferGeometry 삼각팬 박막(주황 발광 반투명) + 금빛 발광 앞날개 라인 + 날개 끝 발톱 + 마디 금빛 인장. 매 프레임 ±0.34rad 펄럭임 + 좌우 스윕.
- **꼬리**: 8마디 사인파 흔들림 + 황금 꼬리날(3.4m).
- **네 발**: 허벅지·정강이 + 발톱 3개씩, 호버링 상태로 늘어뜨림.
- **오라**: 붉은 발광 구체(반경 9.5m, 투명 0.035~0.08 맥동) + 황금 회전 링 + 궤도 불티 14개 + 화염 포인트 라이트(강도 맥동).
- **호버링**: 하늘 y=32에서 13m/s로 급강하 → 옥좌 앞 단상 위 y≈5.6에서 ±0.55m 부유.

### 3.5.3 등장 연출 (피리 선율 후 1.2초)
1. 황금 피리 5음계 선율 + 황금 음파 링 3개 확산(기존 유지).
2. `AudioEngine.playDragonRoar()` 저음 3중 포효 + 화면 골드 플래시 + 카메라 셰이크 1.1.
3. **화염 기둥**(높이 46m 실린더, 1초간 확대·소멸) + 화염/황금 충격 링 4개 + 불티 파편 70개 대폭발.
4. 드래곤이 하늘에서 강하해 착지, 전용 보스 HP 바 등장.
5. 알림: `🐉🔥 【왕드래곤】 대군주 강림!! 하늘을 태우는 포효와 함께 옥좌 위로 내려앉는다!!` / 냥냥이: `"우와!! 진짜 거대한 드래곤이다!! 브레스 조심해!!"`

### 3.5.4 전용 보스 HP 바
- 보스명 `🐉 [왕드래곤] 붉은비늘 대군주`, HP `7,000 + 스테이지 인덱스 × 600` (스테이지 1 = 7,000).
- HP 바 그라디언트를 `#ff2d00 → #ffb703 → #ffe066`로 교체하고, 바 아래에 전용 경고줄 `🐉 화염 브레스 · 화염 파동 · 꼬리 강타 주의!!` 표시. 처치 시 원래 색 복구.
- 피리 버튼 라벨도 상태별로 `피리 (n/50) → 🐉 소환! → 🐉 결전!`로 변화.

### 3.5.6 처치 보상 & 클리어

- 일반 스테이지 보스 처치는 기존대로 `advanceStage()` 진행.

### 3.5.7 함께 고친 v4.3 잠복 버그
1. **사운드 미정의**: `playBossRoar / playShockwave / playLaser / playHurt / playDash / playMeleePunch / playStageClearFanfare` 7종이 호출만 되고 정의가 없어 보스 공격·피격·대시 순간마다 TypeError가 났다 → 7종 신규 합성음 구현(+왕드래곤 전용 3종 추가).
2. **몹 런지 역이동 오류**: `Vector3.subScaledVector`(존재하지 않는 메서드) → `addScaledVector(dir, -0.4)`로 수정, 몹 공격마다 콘솔 에러가 나던 문제 해결.
3. **피리 버튼 중복 바인딩**: `bindAction('fluteBtn')`이 2번 등록돼 한 번 터치에 최대 4회 발동, 1.2초 안에 왕이 여러 번 소환될 수 있었다 → 1회로 정리 + `state.fluteSounding` 가드 추가.
4. **엔딩 통계 `undefined`**: 존재하지 않는 `state.kills` 참조 → `state.totalKills` 신설·집계로 수정.

### 3.5.8 검증용 테스트 훅 (콘솔 전용, 일반 플레이 영향 없음)
- `__scCheat()`: 50마리 조건을 즉시 채우고 피리를 분다(드래곤 소환).
- `__scGod()`: HP 9999, `__scViewDragon(z, pitch, dist)`: 드래곤 정면 시점 이동.
- `__scBreath()`: 화염 브레스 즉시 발사, `__scKillBoss()`: 보스 즉시 격파(엔딩 검증), `__scInfo()`: 보스·스테이지 상태 덤프.
