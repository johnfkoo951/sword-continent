## ✨ 게임 주요 특징

- **🗺️ 18개 스테이지 대원정** — 풀·캣·얼음·불 4대 왕국을 가로지르며 18단계 정복 코스를 돌파
- **👑 4대 왕국** — 하늘에 떠 있는 45m 소드 대륙, 왕국마다 다른 3D 환경과 전용 몬스터
- **💎 10대 신급 스킨** — 드래곤 펀치, 뇌신, 서리 황제, 용암 마신, 폴리 냥이…… 스킨마다 고유 3D 시그니처 모션
- **🍬 사탕 파밍 & 레벨업** — 사탕 30개 = 1레벨. 사탕 하나가 곧 경험치이고 즉시 회복(+12 HP)
- **🔥 극초각성** — 게이지 100%에서 황금 불사조 날개 전개, 3단 시네마틱 컷씬, 15초 절대 무적 · 공격력 5배 · 황금 검기 참격파
- **🤝 2인 실시간 멀티플레이** — 방 코드 `7794`만 맞추면 산이 형과 한 맵에서 협동 보스 레이드 (1P 태용 = 블루, 2P 산이 형 = 레드)

## 🛠 개발 안내

### 태용이에게

태용아, 환영해! 🎉

네가 손으로 만든 이 게임이 이제 진짜 저장소를 갖게 됐어. 여기 있는 건 전부 네 거야 — 마음껏 고치고, 부수고, 다시 만들면서 더 멋진 소드 콘티넨트로 키워 나가자.

처음이라면 이렇게 시작해 보면 좋아:

1. 이 저장소를 **Clone** 하거나, GitHub 웹에서 파일을 바로 열어 보기
2. `docs/PRD_v3.7.md`에서 지금까지의 기획을 다시 읽어 보기 (아빠 리뷰는 `docs/DAD_REVIEW.md`)
3. 고치고 싶은 부분을 **Issue**로 적어 두기 (예: "보스 체력 너무 많아", "새 스킨 아이디어")
4. 고친 파일을 **Commit → Push** 하면 끝!

실수해도 괜찮아. 모든 커밋은 기록으로 남고, 언제든 되돌릴 수 있어. 제일 중요한 건 네가 직접 만들어 보는 거야.

### 로컬에서 열어 보기

게임은 빌드 없이 브라우저에서 바로 실행되는 웹 앱입니다. HTML 파일을 더블클릭하거나, 간단한 로컬 서버를 띄워 확인하세요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

### 커밋 메시지 규칙

| 접두어 | 쓰임 |
| --- | --- |
| `feat:` | 새로운 기능 (스테이지, 스킨, 시스템) |
| `fix:` | 버그 수정 |
| `balance:` | 밸런스 조정 (데미지, 체력, 사탕 수) |
| `art:` | 그래픽·이펙트·모델 |
| `docs:` | 기획서·문서 수정 |

예: `feat: add 19th stage - shadow kingdom`

### 브랜치

- `main` — 언제나 플레이 가능한 최신 버전
- 작업할 때는 `feat/새기능이름` 같은 브랜치를 만들어 커밋하고 `main`으로 합치기
